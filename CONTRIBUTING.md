# Contributing

English · [简体中文](CONTRIBUTING.zh-CN.md)

Thanks for helping make AI explanations clearer and easier to inspect.

## Run locally

```bash
python serve.py
```

Open `http://localhost:8811/`. The gallery and player have no build step and require no API key.
Use the English and Chinese galleries, try playback on a phone-size viewport, and check that opening a board and
returning to the gallery preserve the selected interface language.

## Verify comparison changes

Open compare.html and compare.zh.html. Check a normal pair, a borderline result, a medium-thinking cell with no usable output,
and a question not reviewed at medium thinking. Verify that copying/reopening the link restores both model choices and that changing language preserves the selection.
Open each replay and check the return link. In the gallery, combine filters, reset an empty result and use browser back/forward navigation.

Comparison rendering is in docs/assets/compare.js; shared review labels are in docs/assets/review-ui.js.
Keep all displayed notes and scores tied to their original board IDs, scenarios and thinking settings.

## Verify PDF preview changes

Use the player's PDF preview in desktop Chrome and Edge. Print or save an English maths lesson, a Chinese lesson and an interrupted lesson as A4 landscape, at the default scale with browser headers/footers off.
Check the step count, initial interruption context, erased objects, full narration, page numbers and replay links. Test a long explanation that needs continuation pages; render the saved PDF and inspect Chinese glyphs and formulas as well as extracting the text.
Opening the preview, cancelling print and closing the tab must preserve the source player's progress, pause state and speed. Check fit/actual-size preview on phone-sized screens, and retry after a failed request without showing partial pages.

Preview layout is in lesson-pdf.html and docs/assets/lesson-pdf.{js,css}. Step snapshots reuse player/index.html in a separate renderer. No model API calls are needed.

## Useful contributions

- Additional interface translations. Keep the original recorded board and narration intact.
- Font compatibility reports with operating system, browser version and screenshots of the same recording.
- New, small teaching examples clearly labeled as reference scenarios rather than benchmark results.
- Bug fixes with a concrete reproduction and the expected behavior.

Open an issue before starting a substantial feature. Check the [roadmap](ROADMAP.md) and existing issues first.
For a pull request, explain the user-visible change and how you verified it. Include desktop and mobile screenshots
when changing the interface.

## Preserve the benchmark

Do not silently rewrite the frozen prompts, recorded model outputs, scores, reviewed images or historical costs.
Keep new experiments separate and document their prompt, model/provider, date, settings, sample size and review method.
Generating new examples calls paid model APIs: use your own key and budget, and never commit credentials.

The gallery pages are generated by `python bench/unblind.py`; their shared layout is in `bench/gallery_layout.py`
and `docs/assets/gallery.css`. Update the generator when changing the generated pages, and confirm that regenerating
them does not change the benchmark data.
